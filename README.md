# 🎨 CITE Fest CSS Battle

Welcome to **CITE Fest: CSS Battle!**  
Test your front-end creativity and CSS skills by recreating design challenges using only HTML & CSS.

---

## 💡 How It Works
Each folder inside this repository contains a **CSS Battle problem**.  
Try to **replicate the target design** using only CSS and minimal HTML.

You can:
- 🔍 Open the problem folder to see the design and requirements.  
- 💻 Code your own version from scratch.  
- 🧠 Compare your result with the official solution link.

---

## 🧩 Official Solutions
You can view or attempt the official challenges here:  
👉 **[Try the challenges yourself on Codier.io](https://codier.io/@Charleszx28/challenges)**

Each challenge on Codier also lets you:
- Edit and submit your own code directly in the browser.
- See how close your solution matches the original design.

---

## 🚀 How to Participate
1. Fork this repository.  
2. Choose a problem folder.  
3. Recreate the design using your best CSS skills.  
4. Submit your version via Codier or as a pull request!

---

## 🏆 Tips
- Focus on **accuracy** and **code cleanliness**.  
- Avoid unnecessary HTML elements — pure CSS magic wins points!  
- Feel free to experiment with **transforms**, **gradients**, and **pseudo-elements**.
